# B2 input docs viewer

The [B2 input docs viewer]([https://solps.pages.tok.ipp.cas.cz/solps-doc/extras/b2input/) is a lucid guide to the switches in all B2.5 input files, including `b2mn.dat`, `b2.boundary.parameters` and more. It generates a webpage based on the official SOLPS documentation, where the switch names, default values and descriptions are given.

## Generate the webpage

The viewer webpage is pre-generated by `solps-doc` from several SOLPS-ITER versions, but you are free to generate it yourself.

### Prerequisites

- have a SOLPS-ITER installation (or at least the `b2input.xml` and `xhtml-symbol.ent` files from it)
- clone this repository
- python 3.8+
- install dependencies

  ```bash
  python -m venv venv
  . venv/bin/activate
  pip install -r requirements.txt
  ```

### Usage

Go to this directory, i.e. `cd solps-doc/extras/b2input`, before running the commands below. Check the documentation of the script:

```bash
python generate_html.py --help
```

Assuming the SOLPS-ITER installation is in `/path/to/solps-iter`, generate the webpage to a `./public` directory with the following command:

```bash
# Note that the `xhtml-symbol.ent` file must be in the same directory
# as `b2input.xml`, which is the case in the SOLPS-ITER installation.
python generate_html.py -d "./public" /path/to/solps-iter/modules/B2.5/src/documentation/b2input.xml
```

### Advanced usage (in CI pipeline)

There is a second script, which can download the `b2input.xml` files for one or more SOLPS-ITER versions directly from its git repository. Requires a `versions.yaml` file analogous to the one found in this repository.

```bash
python fetch_b2input_xml_files.py --help
```

```bash
python fetch_b2input_xml_files.py --token $MY_SECRET_TOKEN versions.yaml
```

Now, instead of passing one file, one can pass a directory with multiple suffixed `b2input.xml` files as produced by `fetch_b2input_xml_files.py`. This will generate a webpage for multiple SOLPS-ITER versions, similar to what is found in `solps-doc`.

```bash
python generate_html.py -d "./public" ./
```
